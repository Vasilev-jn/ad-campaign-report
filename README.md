# Отчёт по рекламным кампаниям

## Зависимости

Для работы нужны Python и библиотеки из файла `requirements.txt`.

Установка зависимостей:

```bash
python -m pip install -r requirements.txt
```

## Аргументы

Программа принимает четыре аргумента:

1. Целевая аудитория, например `M_60+_A` или `W_25_45_BC`.
2. Начальный месяц в формате `MM.YYYY`.
3. Конечный месяц в формате `MM.YYYY`.
4. Путь для сохранения презентации.

## Запуск

```bash
python main.py ALL_18_35 01.2025 01.2025 output/report.pptx
```

Программа отбирает целевую аудиторию, считает Reach роликов, выбирает топ-5 рекламодателей и рассчитывает TRP по месяцам.

В архиве используются синтетические примеры данных, не связанные с реальными респондентами или рекламодателями.

## Формулы

```text
Reach = уникальные зрители ролика / размер ЦА * 100
```

```text
TRP = количество просмотров роликов за месяц / размер ЦА * 100
```

Повторные просмотры учитываются при расчёте TRP.

## Сохранение результата

Результат сохраняется в формате PPTX по пути из последнего аргумента. Если указанной папки нет, программа создаст её автоматически.
